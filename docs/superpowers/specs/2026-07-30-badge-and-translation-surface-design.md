# 徽标与译文底板视觉修复设计

## 目标

- 将常规页快捷键徽标和外观页“旁显”徽标从胶囊椭圆改为 Windows 11 风格的小圆角矩形。
- 让旁显窗口与原位覆盖在不透明度 100% 时使用完全不透明的实色底板，避免与网页原文混在一起。

## 设计

- 新建共享 `CompactBadgeStyle`：圆角 5、紧凑内边距、保留当前强调色；两处徽标统一使用。
- 新建动态资源 `TranslationSurfaceBrush`：
  - 深色主题使用不透明深灰表面。
  - 浅色主题使用不透明近白表面。
  - 主题切换时同步更新。
- `SidePanelWindow`、`TextOverlayWindow` 及覆盖层操作栏统一使用该底板。
- 移除底板自身额外的 `0.96/0.97` 透明度；设置页滑杆继续控制窗口整体 `Opacity`。因此 100% 为完全不透明，低值仍按用户设置生效。

## 范围

- 不改变翻译、OCR、快捷键、网页跟随、窗口拖动和译文清除行为。
- 不调整其他按钮、卡片或导航样式。

## 验证

- XAML/集成测试验证两处徽标使用共享小圆角样式。
- 验证两种译文窗口底板自身 `Opacity=1` 并引用实色动态资源。
- 完成 Release 构建及全量测试。
