# 浅色主题可读性与 API Key 掩码设计

## 目标

- 修复浅色模式下两个主按钮和两个徽章出现深色背景、深色文字的问题。
- 已保存 DeepSeek API Key 时显示掩码与最后 4 位，让用户能确认配置仍然存在。
- 完整 API Key 继续只保存在 DPAPI 安全存储中，不进入普通设置、日志或长期 ViewModel 状态。

## 界面范围

采用局部修复，不调整全局 `TextBlock` 样式：

- 常规页“开始框选”主按钮使用强调色文字资源。
- 翻译页“保存”主按钮使用强调色文字资源。
- 常规页快捷键徽章和外观页“旁显”徽章使用强调色文字资源。
- 浅色、深色主题都使用 WPF UI 动态资源，避免写死具体颜色。

## API Key 状态

- 没有已保存 Key：显示密码输入框。
- 已保存 Key：显示只读掩码，例如 `************abd4`，以及“更换”按钮。
- 点击“更换”：切换到空的密码输入框；输入字符仍由 `PasswordBox` 隐藏。
- 未输入新 Key 时保存：保留原 Key，不覆盖安全存储。
- 保存新 Key：写入 DPAPI 安全存储，立即清空输入值并恢复最新掩码。
- 测试连接：有新输入时测试新 Key，否则读取并测试安全存储中的现有 Key。

ViewModel 只保存 `HasSavedApiKey`、掩码文本和本次新输入，不保存已落盘的完整 Key。掩码统一保留最后 4 位；异常短的值全部遮蔽。

## 错误处理与测试

- 安全存储读取失败时不伪装成“已保存”，状态栏显示读取失败。
- 测试连接找不到新 Key 或已保存 Key 时返回明确提示。
- 自动测试覆盖掩码格式、Key 状态切换、保存不误覆盖、测试连接回退到安全存储，以及四个局部控件的主题前景色。
- 发布版本为 `v0.2.3`，通过本地测试、GitHub CI、安装器静默安装/卸载验证后发布。
