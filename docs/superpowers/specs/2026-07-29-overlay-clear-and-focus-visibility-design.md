# 覆盖译文右键清除与来源窗口可见性设计

## 目标

为“原位覆盖”译文增加右键清除操作，并让覆盖译文只在原始来源窗口位于前台时显示。用户切换到其他窗口时译文自动隐藏，切回来源窗口时恢复；已经因网页导航、缩放或标签页变化而失效的译文不得错误恢复。

本次只修改原位覆盖窗口。旁显窗口保持现有行为。

## 用户交互

每个原位覆盖窗口提供 Windows 风格右键菜单：

- `清除此条译文`：只关闭当前译文。
- `清除全部译文`：关闭本次翻译产生的全部覆盖译文。

操作立即生效，不显示二次确认。清除单条后，其他译文继续显示和跟随网页滚动；清除全部后停止当前浏览器跟随会话。

## 来源窗口识别

开始框选前记录当前前台顶层窗口句柄，作为本次翻译的来源窗口。使用 WinEvent 前台窗口变化事件监听焦点，不使用轮询计时器。

当来源窗口：

- 位于前台：允许覆盖译文显示。
- 失去前台焦点、最小化或关闭：隐藏覆盖译文。
- 再次回到前台：恢复仍然有效的覆盖译文。

选择框、屏译设置窗口和其他应用不被视为来源窗口。右键操作不得因为菜单获得输入焦点而使当前译文提前隐藏。

## 可见性状态

覆盖窗口不再由多个功能直接调用 `Show`、`Hide` 或只修改内部卡片可见性，而是组合以下三个独立状态：

1. `UserVisible`：托盘“显示或隐藏全部译文”的用户选择。
2. `SourceWindowActive`：来源窗口当前是否处于前台。
3. `TrackingVisible`：浏览器跟随计算认为译文是否仍在可见区域且会话有效。

只有三个状态都为 `true` 时显示窗口。任意状态为 `false` 时隐藏窗口。

网页导航、缩放、标签页切换等失效事件会把 `TrackingVisible` 永久设为 `false`，因此切回来源浏览器窗口也不会错误恢复旧译文。普通切换应用只改变 `SourceWindowActive`，不会销毁翻译结果。

## 组件调整

### TextOverlayWindow

- 增加右键菜单及“清除此条”“清除全部”事件。
- 保存三个可见性状态，并通过一个内部方法统一应用最终可见性。
- 保留现有复制、旁显和关闭按钮。
- `关闭`按钮与“清除此条译文”语义一致。

### ForegroundWindowMonitor

- 使用 `SetWinEventHook(EVENT_SYSTEM_FOREGROUND)` 监听前台顶层窗口变化。
- 对外发布规范化后的顶层窗口句柄。
- 实现幂等释放，应用退出时注销 WinEvent hook。
- 回调不直接操作 WPF 窗口，由控制器投递到 Dispatcher。

### ApplicationController

- 框选前保存来源窗口句柄，并写入本次翻译工作对象。
- 原位覆盖创建后启动来源窗口监控。
- 收到前台窗口变化时更新全部当前覆盖窗口的 `SourceWindowActive`。
- 托盘显隐通过 `UserVisible` 更新覆盖窗口；旁显窗口仍使用现有显隐方式。
- 清除全部复用结果窗口统一关闭流程。
- 清除单条时从结果窗口集合和浏览器跟随协调器中移除该窗口。

### BrowserFollowCoordinator

- 把覆盖窗口集合改为可移除集合。
- 增加移除单个覆盖窗口的方法。
- 被移除窗口不再接收滚动、移动或可见性更新。
- 最后一条覆盖被移除时，当前跟随会话由控制器停止。

## 异常与边界

- 无法取得来源窗口句柄：保留现有置顶显示，不启用自动隐藏，右键清除仍可用。
- 来源窗口已经销毁：隐藏译文，不自动绑定到同一应用的新窗口。
- 右键菜单打开期间：保持当前译文可见，菜单关闭后重新按前台窗口状态计算。
- 浏览器跟随未安装或不支持当前页面：焦点自动隐藏仍然工作，译文保持静态位置。
- 清除已经关闭的窗口、重复清除全部或重复释放监控器：均为幂等操作，不抛出错误。

## 测试

自动测试覆盖：

- 右键“清除此条”只关闭目标窗口。
- 右键“清除全部”关闭当前全部覆盖窗口。
- 单条移除后不再收到浏览器滚动更新，其他窗口继续移动。
- 来源窗口失去焦点时隐藏、重新获得焦点时恢复。
- 用户托盘隐藏状态下，切回来源窗口不会恢复。
- 浏览器跟随失效后，切回来源窗口不会恢复。
- 最后一条译文关闭后释放焦点监控和浏览器跟随。
- 前台窗口回调从非 UI 线程到达时，窗口操作仍在 Dispatcher 执行。

## 验收标准

- 原位覆盖窗口右键可选择清除此条或清除全部。
- 切换到其他应用后不再看到来源窗口的覆盖译文。
- 切回来源窗口时，仅恢复仍然有效且未被用户隐藏的译文。
- 清除单条不影响其他译文及其网页滚动跟随。
- 不引入持续轮询、重复 OCR 或新的 DeepSeek 请求。
