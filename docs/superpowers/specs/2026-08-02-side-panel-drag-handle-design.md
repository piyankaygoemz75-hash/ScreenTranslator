# 旁显窗口拖动与标题标志设计

## 目标

- 单条旁显窗口顶部整条标题区域都能稳定拖动。
- 拖动不激活或抢走来源应用焦点，不影响正文选字、滚轮和底部按钮。
- “AI 翻译”标志从椭圆改为 `5px` 圆角矩形。
- 连续翻译旁显窗口采用相同的完整标题栏命中范围。

## 实现

- 为两个窗口的标题容器设置 `Background="Transparent"`，使空白区域也参与 WPF 命中测试。
- 单条旁显继续使用现有 `WM_NCLBUTTONDOWN/HTCAPTION` 原生拖动路径，保留 `WS_EX_NOACTIVATE`。
- 连续旁显继续使用现有 `DragMove()` 路径。
- 关闭按钮位于标题容器内但自行处理鼠标事件，因此不会开始拖动。
- 两个标题区域显示 `SizeAll` 光标，明确提示可拖动。
- `AI 翻译` 标志的 `CornerRadius` 固定为 `5`，不改尺寸、颜色或内容。

## 验证与发布

- XAML 回归测试检查两个标题容器都有透明命中背景和拖动光标。
- XAML 回归测试检查 `AI 翻译` 标志圆角为 `5`，禁止恢复为药丸形。
- 运行完整 .NET、浏览器扩展、安装器验证并发布 `v0.2.5`。
